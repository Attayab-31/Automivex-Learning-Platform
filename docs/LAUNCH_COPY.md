## LinkedIn company-page launch post

**Introducing free, project-based technology learning from Automivex.**

We are opening our first self-paced learning path: **Python API Development**.

Participants can use a free long-form learning resource, follow a structured set of milestones, complete a knowledge assessment and build an independent 2026 capstone: a multi-tenant customer-support SaaS API using FastAPI, PostgreSQL, SQLAlchemy, testing and GitHub Actions.

What is included:

- No application, learning, assessment or certificate fee from Automivex.
- Self-paced learning with a clear published roadmap.
- Practical knowledge assessment.
- Independent portfolio project brief.
- Automated public-repository checklist.
- Verifiable course-completion certificate for learners who meet the published criteria.

This is an educational programme—not an internship, job offer or accredited qualification. Learners must confirm that they follow Automivex on LinkedIn and TikTok and subscribe on YouTube when submitting a capstone. These confirmations are self-attested and are not independently verified. Community participation remains optional.

Explore the programme: https://learn.automivex.com
